測量計算アプリ（ST計算＋境界測量）
====================================

使い方
1. ZIPを展開します。
2. survey-app-main フォルダー内の index.html をChromeまたはEdgeで開きます。
3. 上部の「ST計算」「境界測量」ボタンで機能を切り替えます。

統合内容
- 既存ST計算機能を維持
- 境界測量の器械点・後視点・観測点入力
- 観測点数スライダー、点名自動採番、点名編集
- 観測手簿（観測角・中数・水平距離・平面距離）
- 放射法測点座標計算簿
- 点プロット図
- SIMA座標データ出力（CP932、X/Y/Z列、Z=0.000）
- 印刷画面から観測手簿・座標計算簿・プロット図をPDF保存

注意
- PDF出力はブラウザーの印刷画面を利用します。「PDFに保存」を選んでください。
- SIMAはTREND-ONEで取り込み確認をしてください。ソフト側の設定やバージョンによって取込条件が異なる場合があります。
- GitHub Pagesへ公開する場合は、ZIP内のファイルを既存リポジトリにアップロードしてください。service-worker.js のキャッシュ名は更新済みです。
